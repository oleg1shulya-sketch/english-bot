# English Trainer Bot

Бот для закрепления материала с уроков английского по аудиозвонку.
Ты пересылаешь ему сообщения преподавателя как есть — он сам понимает,
что это за задание, и превращает его в тренировку с автопроверкой.

## Что бот понимает

| Что присылает преподаватель | Во что превращается |
|---|---|
| `I am happy – Am I happy? – I am not happy.` | Дано утверждение → построй вопрос, потом отрицание |
| `1. I ... in the theatre. 2. We ... in the yard.` | Вставь am / is / are (проверка автоматическая) |
| `1. Я в парке. 2. Мы в углу.` | Переведи на английский, бот сверяет с эталоном |
| `Abroad`, `On holiday`, `In bed` | Карточки со словами |
| `word - перевод` | Классические карточки (запасной формат) |

Тип определяется автоматически — ничего указывать не нужно, просто форвардни сообщение.

## Команды

- `/start` — инструкция
- `/practice` — смешанная тренировка по всему пройденному (основная команда)
- `/drill` — только трансформации (вопрос / отрицание)
- `/gaps` — только пропуски am/is/are
- `/translate` — только перевод с русского
- `/vocab` — карточки со словами
- `/lessons` — список загруженных уроков
- `/stats` — прогресс и список слабых мест
- `/reset` — сбросить текущую тренировку

Во время тренировки просто пиши ответ текстом. `стоп` — прервать.

## Как повторяется материал

Каждое задание имеет «коробку» от 1 до 5 (система Лейтнера). Ответил верно —
коробка повышается, и задание встречается реже. Ошибся — коробка сбрасывается
в 1, и оно возвращается чаще. Так слабые места прорабатываются больше.

## Обновление на Railway

Файлы проекта: `bot.py`, `lessons.py`, `requirements.txt`, `Procfile`.

1. Зайди в свой репозиторий `oleg1shulya-sketch/english-bot` на GitHub.
2. `Add file` → `Upload files` → загрузи новые `bot.py` и `lessons.py`
   (перезапишут старые) — **важно: `lessons.py` это новый файл, без него бот не запустится**.
3. `Commit changes`.
4. Railway увидит коммит и передеплоит сам за 1–2 минуты.

## Чтобы прогресс не терялся при передеплое

Railway стирает файлы при пересборке, а прогресс лежит в `data.json`.
Чтобы этого не происходило:

1. В Railway открой свой сервис `worker` → вкладка `Settings` → раздел `Volumes`.
2. Нажми `Add Volume`, укажи Mount path: `/data`.
3. Во вкладке `Variables` добавь переменную `DATA_DIR` со значением `/data`.
4. Сервис передеплоится, и прогресс будет храниться на постоянном диске.

